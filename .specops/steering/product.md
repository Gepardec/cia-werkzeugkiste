## Product Overview

The repository provides small operational tools and container images, including a local Grafana log-analysis stack that can switch between Loki and VictoriaLogs.

## Target Users

Engineers investigating local application, JSON, and HTTP access logs.

## Key Differentiators

The log stack is self-contained, Docker Compose based, and intended to make local log ingestion and querying predictable.
